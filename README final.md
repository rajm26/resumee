# Raj Mishra — A Personal Journal · Kept on a Pond

A bespoke, archival personal portfolio & journal website created for **Raj Mishra** (21-Year-Old First-Generation Entrepreneur, IIM Bangalore BBA candidate, and Founder & Corporate Director).

Directly inspired by the botanical pond & tactile archival stationery design theme of [dhrovya-portfolio.vercel.app](https://dhrovya-portfolio.vercel.app).

Built with **Pure Semantic HTML5 and Modern CSS3** (zero JavaScript frameworks, zero build steps, 100% compliant with standard web development coursework requirements, ready for GitHub Pages hosting).

## 🍃 Theme & Creative Direction: "A Personal Journal, Kept on a Pond"

1. **The Pond (Dark Aquatic Atmosphere)**:
   - Deep emerald waters (`#020b07`, `#04130d`, `#071d17`, `#0a2e1e`).
   - Swimming koi silhouettes with articulated tail wiggles (`@keyframes koi-swim`, `@keyframes koi-tail`).
   - Animated water ripples expanding across the pond (`@keyframes pond-ring`).
   - Bobbing floating lily pads with lotus blossoms (`@keyframes lily-bob`).
   - Giant submerged relief watermark (`RAJ MISHRA`) etched into the pond floor.

2. **The Journal Sheets (Tactile Archival Parchment)**:
   - Creamy deckled paper sheets (`#f4eee1`, `#ebe5d5`, `#e8e1cf`) resting atop the water with fine ruling lines and SVG paper grain texture.
   - Stacked book drop shadows (`box-shadow: 0 30px 70px -15px rgba(0, 0, 0, 0.65)`).
   - Semi-transparent frosted scotch tape strips (`rgba(255, 255, 255, 0.68)`) pinning polaroid frames and index notes.

3. **The Cutting Mat**:
   - Self-healing dark green drafting mat (`#0d2319`) with coordinate grids.
   - Pinned skill fragments (High-Ticket Funnels, Telegram Scaling, 25k Concurrency Live Ops, Database Schema, Financial Consolidations, Brand IP).
   - Embedded physical 1-page minimalist white paper resume with one-click print/PDF button.

4. **Typography Pairing**:
   - **Display / Chapter Titles**: `'Noto Serif Display'`, serif (high-contrast, editorial gravitas).
   - **Literary Subheadings / Quotes**: `'Cormorant Garamond'`, serif (poetic, italic reflections).
   - **Technical UI / Metadata**: `'Instrument Sans'`, sans-serif (clean modern labels, pill tags, dates).
   - **Handwritten Marginalia**: `'Caveat'`, cursive (personal margin notes, polaroid captions, botanical ink signature).

5. **Pure CSS Micro-Interactions**:
   - **Floating Glass Pill Nav**: Centered frosted pill with duck-under-umbrella brand crest and chapter links.
   - **Interactive Desk Notebook**: 5 numbered page tabs powered by pure CSS `:checked` radio selectors (zero JavaScript needed to switch pages!).
   - **Table of Chapters Drawer**: Full-screen parchment index modal powered by pure CSS `:target`.
   - **Physical Print Stylesheet**: Clean `@media print` rules for physical printing (`Cmd+P` / `Ctrl+P`).

## 🚀 How to Host on GitHub Pages (Step-by-Step)

### Option 1: Drag-and-Drop on GitHub Web (2 Minutes)
1. Go to [GitHub.com/new](https://github.com/new) and create a **Public** repository (e.g. `raj-mishra-portfolio` or `portfolio`).
2. Click **Add file** -> **Upload files**.
3. Select and upload the 3 files from this directory:
   - `index.html`
   - `style.css`
   - `README.md`
4. Click **Commit changes**.
5. Go to **Settings** -> **Pages** (in the left sidebar).
6. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
7. Your site will be live at:
   `https://<your-username>.github.io/<repository-name>/`
